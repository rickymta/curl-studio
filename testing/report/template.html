1. Tính năng mới đã triển khai

1.1 Hộp thoại “Save changes?” khi đóng tab (giống Postman)

  • Áp dụng cho mọi cách đóng: nút ×, Ctrl+W, chuột giữa, menu chuột phải (Close / Close others / Close all).
  • Ba lựa chọn: Don't save, Cancel, Save changes. Với request chưa từng lưu, “Save changes” mở hộp thoại Save request (chọn collection/folder) rồi mới đóng tab.
  • Đóng nhiều tab: tab sạch đóng ngay, tab có thay đổi được hỏi lần lượt, kèm dòng báo “(N more tabs after this one)”.
  • Checkbox Always discard unsaved changes when closing a tab: lưu vào Settings, và tắt lại được trong Settings.

1.2 Popover khi rê chuột lên biến {{variable}}

  • Hiện giá trị hiện tại và nguồn (E Environment, C Collection, G Globals) theo đúng thứ tự ưu tiên khi gửi request.
  • Sửa trực tiếp: Enter hoặc rời ô để lưu, Esc để huỷ. Với biến môi trường, sửa vào current value nếu đã có, giống Postman.
  • Biến chưa định nghĩa: viền đỏ (trên thanh URL và trong bảng), popover báo “Unresolved” và cho chọn scope để thêm biến mới.
  • Biến động ({{$guid}}, …): hiện mô tả kèm giá trị ví dụ. Có liên kết “Open environment / collection” để mở trình chỉnh sửa tương ứng.
  • Có ở mọi ô một dòng hỗ trợ biến: URL, Params, Headers, form body, Auth.

1.3 Điều chỉnh kích thước khung và cột

  • Kéo vạch chia Request/Response để đổi độ cao (vùng nắm 7px, nhấp đúp để đặt lại, nhớ theo từng loại editor).
  • Kéo đổi độ rộng các cột Key / Type / Description trong mọi bảng key-value (Params, Headers, form-data, …). Độ rộng được nhớ và dùng chung giữa các bảng; nhấp đúp để đặt lại.
  • Cột trái kéo được độ rộng như trước.

1.4 Cột trái: tìm kiếm và thêm mới

  • Ô tìm kiếm có phím tắt Ctrl+K, nút xoá, Esc để xoá. Chỗ khớp được tô sáng, và có thông báo khi không có kết quả.
  • Collection/folder khớp tên thì hiện toàn bộ request bên trong. Tìm theo cả tên lẫn URL.
  • Nút + mở menu theo ngữ cảnh: New collection, các loại request (HTTP, GraphQL, WS, SSE, gRPC, MQTT), Import; ở tab Environments là New/Import environment; ở tab Load là New load test.
  • Nút + hiện khi rê chuột trên từng collection/folder để thêm nhanh request hoặc folder con.
  • Trạng thái mở/đóng folder được nhớ qua lần tìm kiếm và lần khởi động lại.

6. Chưa kiểm thử trong đợt này

  • Cửa sổ desktop Tauri (pnpm tauri dev/bản build): hộp thoại mở/lưu file native, menu hệ thống. Đợt này test qua trình duyệt với cùng core Rust.
  • HTTPS/TLS (mock chỉ có HTTP), proxy, MQTT qua TLS, gRPC TLS và gRPC streaming (server/client/bidi).
  • OAuth 2.0 lấy token, AWS SigV4 với AWS thật; Runner với file dữ liệu CSV/JSON.
  • Executor arrival-rate, iterations và màn so sánh run: đã test ở đợt trước, đợt này không chạy lại.
  • Hiệu năng UI với collection rất lớn (hàng nghìn request) và chế độ sáng của app.
